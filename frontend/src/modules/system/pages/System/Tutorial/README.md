# 教程中心 / 用户手册 同步纪律（D-655）

## 数据同源

- 教程内容 = 本目录 `tutorialDataBasic/` + `tutorialDataSystem/` 下的 TS 数据文件（13 个文件）。
- 「下载用户手册」按钮（`userManual.ts`）**实时从这同一份数据编译成打印 HTML**，浏览器打印选「另存为 PDF」即得离线手册。
- **没有第二份手册文档**：教程改了，手册自动跟着新。封面带 `__BUILD_COMMIT__` 版本戳 + 生成日期 + 收录篇数，一眼可核对手册新鲜度。

## 维护规则

1. **界面/流程改动必须带教程**：任何 D 号迭代改了某模块的界面形态或操作流程，若该模块已有教程文件，必须**同批**更新对应教程步骤；新模块上线必须补教程（在 `tutorialDataBasic` 或 `tutorialDataSystem` 对应文件里加 `Tutorial` 条目）。
2. **旧内容清理**：被改掉的旧交互描述要删，不要堆"以前是这样现在又不一样"的叠加描述。
3. **图片**：教程步骤可带 `image` 截图（手册与网页共用）；截图要跟当前线上界面一致，界面改版时截图一并换。
4. **视频**：`videoUrl` 只支持 Bilibili / MP4 直链（YouTube 在国内不可达，教程页会提示）；手册里视频只出链接文字。
